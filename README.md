# M6F+ gegen Halten

Interaktive Statistik der systematischen Strategie **M6F+** für ETH und BTC (in Euro) im Vergleich zum einfachen
Halten – Wertentwicklung, Rückgänge, Kalenderjahre und das Ergebnis für jeden möglichen Starttag seit Februar 2020.

Statische Website ohne Build: `index.html`, `style.css`, `app.js` und die täglichen Werte in `data.js`.
Lokal ansehen: `python3 -m http.server` im Ordner starten und `http://localhost:8000` öffnen.

Backtest mit Gebühren (0,09 % je Order, 0,03 % Spread), ohne Steuern. Vergangene Ergebnisse sind keine Garantie für
die Zukunft. Keine Anlageberatung.
